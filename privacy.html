Privacy Policy – OneHand rclone

OneHand rclone is a personal OAuth client used by its owner with rclone. This policy describes how it handles Google user data.

Data accessed

With the owner's permission granted through Google OAuth, rclone uses the Google Drive API to list, read, upload, update and delete files in the owner's own Google Drive.

Purpose

The data is used only to manage the owner's own files in Google Drive, including distribution files for the owner's OneHand app. It is not used for any other purpose.

Sharing and use

  • Google user data is not sold.
  • Google user data is not used for advertising.
  • Google user data is not transferred or disclosed to third parties.
  • No Google user data is collected on any server operated for this client. Files move directly between the owner's computer and Google Drive.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Credentials

OAuth credentials are stored only in the local rclone configuration on the owner's computer.

Revoking access

Access can be revoked at any time from the Google Account settings: https://myaccount.google.com/permissions.
